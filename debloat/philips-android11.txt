# Philips Android TV 11 (TP Vision, MediaTek "PH1M" platform)
# Tested on: 50PUS8507/62, firmware PH1M_EA_9970A, Android 11, armeabi-v7a.
# Same platform: 2020-2022 PUS7xxx/8xxx/OLED7xx sets. Check your own package list first.
#
# Format:  package <TAB> group <TAB> reason (English) <TAB> reason (Turkish)
# Method:  pm disable-user --user 0 <package>      (never uninstall)
# Undo:    pm enable <package>                     (or scripts/tv.sh restore)
#
# Groups:
#   telemetry   logging / tracking / crash upload
#   unused      features most people never use (keep the ones you use!)
#   online      Philips cloud services (NetTV, registration incl. ACR tracking)
#   regional    pre-installed apps that only exist in some countries
#   preinstalled other pre-installed apps
#   launcher    only together with an alternative launcher (Projectivy etc.)
#

#   com.google.android.apps.mediashell, com.phorus.playfi.tv, io.mimi.tvapp
